# Canon and Development Templates

This directory contains the reusable Markdown templates for *The Brass Guardian / Aetherhaven* project.

Templates are structural starting points, not canonical content. Creating or filling a template does not establish canon; creative changes remain subject to the author's approval rules in [`../agents/shared/AUTHORSHIP_AND_ARTISTIC_CONTROL.md`](../agents/shared/AUTHORSHIP_AND_ARTISTIC_CONTROL.md).

## Available Templates

- [Character Profile](Character_Profile_Template.md)
- [Organization Profile](Organization_Profile_Template.md)
- [Location Profile](Location_Profile_Template.md)
- [Artifact Profile](Artifact_Profile_Template.md)
- [Story Arc Profile](Story_Arc_Profile_Template.md)
- [Historical Event Profile](Historical_Event_Profile_Template.md)

Use the repository's [Canon Markdown Standard](../docs/standards/CANON_MARKDOWN_STANDARD.md) when creating or revising canonical Markdown.
