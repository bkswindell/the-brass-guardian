# Aetherhaven Artifact Image Slate

> **Development reference and spoiler warning:** These files document the planned and completed archival plates, recovered objects, diagrams, photographs, rubbings, and evidence records used throughout *The Brass Guardian*. The active Markdown canon controls whenever the original slate and later development differ.

## Source and Usage Rules

- Each artifact has one authoritative Markdown file in this directory.
- Artifact files describe the object or image concept; they should link to character, organization, location, and story-arc profiles rather than duplicating their full history.
- Active images are embedded from `../art/`.
- `../unused/` is excluded from canon and must never be used as a reference source.
- `canonical-working-artifact` means the artifact concept has active art and is part of working canon.
- `planned-artifact-concept` means the slate entry is preserved for development but its final art or exact canon may remain unfinished.
- `requires-canon-review` means the slate references a concept not yet supported by the active Markdown library and must not be promoted to canon without approval.
