# Aetherhaven Canonical Character Memory

This directory contains one Markdown file per canonical character. Profiles are written as durable story-development records rather than prose intended for direct publication.

## File Standard

Each profile includes:

- YAML front matter for indexing and future automation.
- A canonical summary.
- Public identity and story function.
- Relationships.
- Hidden history and temporal significance.
- Personal artifacts.
- Visual continuity.
- Story opportunities.
- Staged revelations.
- Continuity constraints.
- Open canon questions.

## Official Map-Reference Tone

The map's numbered locations and restricted areas use distinct public-facing voices:

- **Locations 1–24:** welcoming, upbeat, wondrous, and intriguing, with only a light warning where appropriate.
- **Areas A–F:** cautionary, restrictive, or official-warning language that still invites curiosity and makes the forbidden location feel worth exploring.

Public map references preserve important named points of interest and remain spoiler-light. Full location profiles may contain hidden history, political conflict, antagonist activity, temporal mysteries, and staged revelations.

See [Map Location Reference Style Guide](Map_Location_Reference_Style_Guide.md).

## Location Profile Rule

Canonical summaries for districts, cities, lands, and regions must include:

- the location's defining atmosphere and civic or narrative role,
- its governing or social context,
- and its important established points of interest.

Named landmarks and venues already introduced in canon must not disappear when a location profile is expanded. Each location profile also contains a dedicated **Points of Interest** section.
