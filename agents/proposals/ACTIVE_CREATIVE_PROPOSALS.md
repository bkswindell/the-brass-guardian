## Proposal Entry Template

Copy this structure when adding a proposal:

```markdown
## YYYY-MM-DD — Proposal Title

**Status:** PROPOSED  
**Proposed by:** GPT / Hermes / Claude / Gemini / Author / Other  
**Area:** Character / Story / World / Location / Organization / Artifact / Visual / Website / Other

### Proposal

Concise description of the idea.

### Why It May Help

What problem, opportunity, theme, story need, or experience this proposal could serve.

### Canon Dependencies

Existing canon files, characters, mysteries, or decisions that constrain the proposal.

### Risks / Questions

Continuity risks, spoiler concerns, unresolved choices, or consequences the author should consider.

### Author Decision

Awaiting review.

### Promotion Record

Not promoted to canon.
```

## Approval Rule

An AI agent may add a **PROPOSED** entry when an idea is worth preserving.

Only the author may cause the proposal to become an accepted material creative decision.

When the author approves it, record the approval clearly and promote only the approved scope into the proper canonical or project files.
