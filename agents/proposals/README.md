# Creative Proposal Staging Area

This directory is the durable staging area for **unapproved creative proposals** produced or discussed by AI collaborators working on **The Brass Guardian / Aetherhaven**.

Its purpose is to preserve useful ideas across sessions and between agents **without allowing those ideas to contaminate canon**.

## Governing Rule

**Nothing in `/agents/proposals/` is canon merely because it is written here.**

The human author retains final artistic and canonical authority under:

`/agents/shared/AUTHORSHIP_AND_ARTISTIC_CONTROL.md`

All material creative changes require explicit author approval before they may be promoted into canonical Markdown, accepted visual canon, published narrative content, or other authoritative project sources.

## What Belongs Here

Use this directory for creative ideas worth preserving between sessions, including:

- possible story plots or side-story concepts;
- proposed characters or character developments;
- possible locations, organizations, artifacts, technologies, traditions, or historical events;
- alternative explanations for unresolved mysteries;
- illustration concepts or visual-development ideas;
- proposed names, terminology, symbolism, or motifs;
- possible website narrative experiences;
- competing approaches the author has not yet chosen between;
- AI-generated concepts that may be useful later but are not approved.

Do **not** place ordinary implementation notes, temporary brainstorming chatter, or already-approved canon here.

## Proposal Status

Every durable proposal should make its approval state obvious.

Recommended statuses:

- **PROPOSED** — created for author consideration; not approved.
- **UNDER REVIEW** — actively being discussed with the author; not approved.
- **APPROVED FOR CANON** — explicitly approved by the author and awaiting or undergoing promotion to the owning canonical files.
- **APPROVED FOR USE** — approved for a specific non-canon purpose, such as a website experiment or illustration concept, without necessarily establishing lore.
- **REJECTED** — considered and rejected by the author.
- **SUPERSEDED** — replaced by a newer proposal or decision.
- **PARKED** — intentionally preserved for possible future consideration.

Do not use an approval status unless the author explicitly granted that approval.

## Promotion to Canon

When the author approves a proposal as canon:

1. identify the canonical file or files that own the information;
2. apply only the approved material change;
3. update `/agents/shared/DECISIONS.md` when the decision has durable significance;
4. update cross-links, indexes, or related files as appropriate;
5. change the proposal status to **APPROVED FOR CANON** and record where it was promoted;
6. preserve the proposal entry for provenance unless the author specifically requests removal.

Promotion is not permission to expand the approved idea with additional consequential AI-created details.

## Rejected Ideas

Rejected proposals may remain here when useful as development history so future agents do not repeatedly suggest the same discarded direction.

A rejected idea must remain clearly labeled **REJECTED** and must never be treated as negative canon unless the author explicitly establishes that the idea is canonically impossible.

## Active Proposal Index

Use [`ACTIVE_CREATIVE_PROPOSALS.md`](ACTIVE_CREATIVE_PROPOSALS.md) as the lightweight shared index for current proposals.

If a proposal becomes complex enough to need substantial notes, alternatives, images, or research, create a dedicated Markdown file in this directory and link it from the active index.

## Agent Rule

When an AI collaborator develops an idea that is worth preserving but has **not** been explicitly approved by the author, store it here rather than modifying an owning canon file.

**Preserve the possibility without pretending the decision has been made.**
