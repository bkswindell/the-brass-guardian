# Curated Public Projection

This directory is the only content source approved for future public archive routes.

The internal canon library is **not** imported or rendered automatically. Each record in `manifest.json` must be a deliberately written public projection with explicit author approval, a safe spoiler classification, and one or more auditable source paths.

The manifest intentionally begins with no entries. Repository presence does not grant publication approval.

See [`../../docs/PUBLICATION_BOUNDARY.md`](../../docs/PUBLICATION_BOUNDARY.md) for the field contract, approval workflow, and build-time safeguards.
